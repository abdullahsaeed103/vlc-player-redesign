# VLC Player — Browser Redesign Recreation

A browser-based media player inspired by a modern VLC redesign concept. This project recreates the interface as an interactive player using HTML, CSS, and JavaScript.

**Live preview:** https://vlc-player-redesign.vercel.app/

> This is an independent, unofficial fan project. It is not affiliated with or endorsed by VideoLAN or VLC media player.

## Project links

## Features

- Browser-based audio and video playback
- Playlist and queue handling
- Import media with a file picker, folder selection, or drag and drop
- Subtitle loading and subtitle controls
- Playback progress and resume support
- Keyboard shortcuts and accessible menu navigation
- Appearance and playback settings
- Responsive layout for different screen sizes
- Screen Wake Lock support in browsers that provide the API

Browser support and available codecs vary by browser and media format. Some controls depend on browser APIs and the type of media being played.

## Run locally

No build step or package installation is required.

1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. Choose media using the file picker or drag files into the player.

For more consistent file-handling behavior, serve the project with a local static server instead of opening the HTML file directly.
